# A Little Furniture Mod

A Fabric mod for Minecraft 26.3 that adds cozy, usable furniture and accessories for building and decorating.

## Features

- Furniture for kitchens, bathrooms, bedrooms, living rooms, and outdoor builds
- Storage furniture with usable inventories
- Connected furniture, including sofas, tables, desks, vanities, and bookshelves
- Chairs and stools players can sit on
- Lamps and ceiling lights with switchable lighting
- Ladders, fences, and decorative stone and wooden steps
- Wearable and placeable accessories, including a witch hat and white bunny ears
- Crafting recipes and recipe unlocks for mod items

## Requirements

- Minecraft Java Edition 26.3
- Fabric Loader
- Fabric API

## Installation

1. Install Fabric Loader for Minecraft 26.3.
2. Install Fabric API for Minecraft 26.3.
3. Download the mod from the project's Releases page when a release is available.
4. Put the mod `.jar` in your Minecraft `mods` folder and launch the Fabric profile.
